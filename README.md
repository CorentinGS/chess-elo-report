# Chess Elo Report

F# analysis comparing FIDE player data with Universal Rating data.

## Data

The full data files are intentionally not committed:

- `EloAnalysis/players.xml` is the FIDE XML rating list.
- `EloAnalysis/ratings.csv` is the Universal Rating CSV export.
- `players_cache.json` is generated by the app after merging the source files.

Download the source data before running the full analysis:

```powershell
.\scripts\download-data.ps1 -UrRatingsUrl "https://example.com/path/to/ratings.csv"
```

The script downloads `players.xml` from FIDE by default. Pass a Universal Rating CSV URL with `-UrRatingsUrl`, or set `UR_RATINGS_URL`, so it can also write `EloAnalysis/ratings.csv`.

Then run:

```powershell
dotnet run --project EloAnalysis
```

The small `players_sample.xml` and `ratings_sample.csv` files stay in Git because the F# type providers use them at compile time.
